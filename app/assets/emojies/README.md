# Discord emoji assets

These PNGs use the existing emoji-upload naming scheme. Most use lowercase
letters, digits, and underscores; the historical `ruh-kaan` and `shen-rao`
source filenames are retained for backward compatibility with the already
uploaded compact Discord emoji names `ruhkaan` and `shenrao`.

- `champions/` contains one existing champion icon per file. Upload files with
  their filename (without `.png`) as the emoji name, for example `varesh`,
  except for the two historical hyphenated files noted above.
- `battlerites/` is a flat directory of battlerites. Upload each with its
  filename (without `.png`) as the emoji name, for example
  `varesh_mouse1_control`.

There are 28 champion icons and 414 battlerite icons. The bot integration is
deliberately not enabled until the required custom emojis have been uploaded.
